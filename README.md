# CAJ 转 PDF 转换器（免费 · 本地 · 离线）

一个完全在本机运行的中国知网（CNKI）CAJ 家族文件转 PDF 工具。**无需联网、无需上传文件、无广告、无水印**，转换核心仅使用 Python 标准库，图形界面基于开源免费的 PySide6（Qt）。

---

## 一、特性

- **完全本地、离线**：所有读取、解密、解析、重组都在你的电脑上完成，文件不会被上传到任何服务器。
- **免费开源**：转换引擎为纯 Python 标准库实现；GUI 使用 LGPL 授权的 PySide6，可自由使用。
- **批量转换**：一次添加多个文件，或直接添加整个文件夹（自动递归查找）。
- **保留文字与结构**：直接提取/修复内嵌 PDF，可选择、检索文字（不是把页面打印成纯图片）。
- **自动修复**：内置 PDF 对象扫描、Catalog/Pages 补全、xref 交叉引用表重建，能处理对象乱序、根对象缺失等问题。
- **拖拽支持**：可把文件或文件夹直接拖入窗口。
- **同名不覆盖**：批量转换时若不同源文件指向同一输出名，会自动追加 `_1`、`_2`，避免互相覆盖。

---

## 二、运行环境

- 操作系统：Windows 10 / 11（64 位）。
- Python：3.8 或更高版本。
- 界面依赖：PySide6（启动脚本会在缺失时自动安装，无需手动操作）。

> 本工具的启动脚本会自动在 PATH、DoubaoWork 内置 Python 以及常见安装目录中查找 Python，因此即使 Python 没有加入系统环境变量，通常也能直接启动。

## 三、快速开始

1. 双击项目目录下的 **`start.bat`**。
2. 首次运行若提示安装 PySide6，请等待其自动完成（仅第一次需要，之后离线可用）。
3. 在弹出的窗口中点击 **“添加文件”** 或 **“添加文件夹”**，也可以直接把文件拖入列表。
4. 选择输出位置（默认“输出到各源文件所在目录”，也可取消勾选并指定统一目录）。
5. 点击 **“开始转换”**，等待进度条完成；日志区会显示每个文件的结果与输出路径。
6. 点击 **“打开输出文件夹”** 即可查看生成的 PDF。

## 四、支持的格式与原理

| 格式 | 扩展名 | 是否支持 | 处理方式 |
| --- | --- | --- | --- |
| CAJ | `.caj` | 支持 | 最常见。本质是内嵌 PDF，外层加了 CNKI 头/尾，且常被剥离 Catalog/Pages；工具通过文件头指针精确定位 PDF，补全结构并重建 xref。 |
| KDH | `.kdh` | 支持 | 简单 XOR 加密包裹的 PDF。跳过前 254 字节，用固定口令 `FZHMEI` 循环异或解密，再截断 EOF 并修复。 |
| PDF | `.pdf` | 支持 | 本身就是 PDF，做一次规范化重写（重建 xref），不改变内容。 |
| HN / C8 | `.nh`、`.c8` | 暂不支持 | 使用 JBIG/JBIG2 图像压缩，多见于硕博学位论文。需要专用图像解码器，本工具未内置，会明确提示而不是产出残缺文件。 |
| TEB | `.teb` | 暂不支持 | 知网另一专有格式，建议用官方阅读器打印为 PDF。 |

> CAJ 是专有格式，相关转换基于公开开源项目对其结构的逆向分析，无法保证 100% 覆盖所有变体。

## 五、命令行用法

除图形界面外，也可以直接用命令行调用核心引擎（适合脚本化、自动化）：

```bash
# 转换单个文件（输出到源文件同目录）
python caj_converter.py paper.caj

# 转换多个文件并指定输出目录
python caj_converter.py a.caj b.kdh -o D:\output

# 转换整个文件夹（递归）
python caj_converter.py D:\papers -o D:\output

# 指定输出文件路径（单文件）
python caj_converter.py paper.caj -o paper.pdf
```

运行 `python caj_converter.py --help` 可查看完整参数。

## 七、常见问题（FAQ）

**Q1：双击 start.bat 闪退或提示找不到 Python？**
A：请确认已安装 Python 3.8+。若已安装仍失败，可重新运行 Python 安装包并勾选 “Add Python to PATH”，或在命令行手动执行 `python caj_gui.py` 查看具体报错。

**Q2：首次启动为什么要联网？**
A：只有在缺少界面组件 PySide6 时才需要联网安装一次；安装完成后，日常转换完全离线，且核心引擎本身不依赖网络。

**Q3：转换后能选择文字吗？**
A：可以。CAJ/KDH 内嵌的是 PDF 数据，本工具直接提取并修复，文字可选择、可检索；这与“打印成图片”的方式不同。

**Q4：我的 `.nh` 文件转换失败怎么办？**
A：`.nh` 多为 HN/C8 图像编码，本工具暂不支持。可使用知网官方 **CAJViewer** 打开，通过“打印 → Microsoft Print to PDF”另存为 PDF（该方式得到的是图片型 PDF）。

**Q5：会泄露我的论文吗？**
A：不会。程序不包含任何网络上传逻辑，所有处理均在本地完成；你也可以断网后运行验证。
